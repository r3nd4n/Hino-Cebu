## Sampling Rate

- **After every task commit:** Run `node --test tests/visual-polish.test.mjs` plus the closest existing surface test.
- **After every plan wave:** Run `npm test && npm run typecheck`.
- **Before `$gsd-verify-work`:** Run `npm run check` and complete the manual responsive/accessibility record.
- **Max feedback latency:** 10 seconds for the focused source-contract suite.
