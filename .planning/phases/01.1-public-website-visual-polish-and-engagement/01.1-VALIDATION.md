## Plan 01 Prerequisite and RED Contract

Plan `01.1-01` is the Wave 0 prerequisite for every implementation plan. Task 1 creates all task-prefixed contracts, runs them once, and records every observed failing full name in `EXPECTED_RED_TEST_NAMES` inside `tests/visual-polish-wave0-red.mjs`. The meta-runner spawns the contract suite, requires every recorded RED name to fail, rejects any unrecorded failure plus syntax/module-load failures, permits named contracts already green in the baseline, and exits zero only when the actual failure set exactly matches the recorded RED set. Task 2 then creates the manual evidence template and runs only `^P01-T02:`, which must turn green. No later task runs the meta-runner.
