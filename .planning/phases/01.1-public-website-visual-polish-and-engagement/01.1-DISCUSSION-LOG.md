## Visual character and typography

### Overall personality

| Option | Description | Selected |
|--------|-------------|----------|
| Premium industrial | Strong, polished commercial character with restrained red accents and truck-led visuals | Yes |
| Corporate clean | Conservative presentation closer to Hino Philippines | No |
| Friendly local | Softer and warmer dealership character | No |

### Typography treatment

| Option | Description | Selected |

| Industrial headings plus neutral body | Slightly condensed headings with a neutral reading face | No |
| One unified typeface | One professional family throughout | No |

### Surface treatment

| Option | Description | Selected |

### Light and dark balance

| Option | Description | Selected |
|--------|-------------|----------|

## Header, navigation, and motion

### Upper phone strip

| Option | Description | Selected |
|--------|-------------|----------|
| Remove it entirely | Begin with the branded main header and retain phone access elsewhere | Yes |
| Keep a slim contact strip | Retain a quieter phone/hours utility bar | No |
| Use a local-information strip | Replace phone with branch/status messaging | No |

**User's choice:** Remove it entirely.

### Desktop navigation structure

| Option | Description | Selected |
|--------|-------------|----------|
| Concise task-first navigation | Six high-value destinations plus emphasized quote action | Yes |
| Show every major destination | Keep all major routes visible in the header | No |
| Grouped dropdown navigation | Organize routes beneath category menus | No |

**User's choice:** Concise task-first navigation.

### Current, hover, and focus states

| Option | Description | Selected |
|--------|-------------|----------|
| Red underline plus soft hover | Persistent active underline, neutral hover, visible focus outline | Yes |
| Rounded tab treatment | Pill-like active and hover states | No |
| Typography only | Use weight and color without underline/background | No |

**User's choice:** Red underline plus soft hover.

### Motion level

| Option | Description | Selected |
|--------|-------------|----------|
| Subtle micro-motion | 180-220 ms nav/menu transitions; no page animation | Yes |
| More expressive transitions | Animated dropdowns and page-content shifts | No |
| Almost static | Immediate state changes with minimal animation | No |

**User's choice:** Subtle micro-motion.
**Notes:** Motion must switch off for visitors who prefer reduced motion.
