# Phase 01.1 — UI Design Contract

> Visual and interaction contract for public website visual polish and engagement. Generated by gsd-ui-researcher; awaiting gsd-ui-checker verification.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — preserve the existing repository-owned design system; shadcn initialization was explicitly declined on 2026-08-22 |
| Preset | not applicable |
| Component library | none; extend existing React components and `src/app/globals.css` |
| Icon library | none; use small repository-owned inline SVGs sourced from official platform brand resources, with provenance recorded and decorative paths hidden from assistive technology |
| Font | Barlow, self-hosted through `next/font/google`, weights 400 and 700 only; fallback `Arial, sans-serif` |

The visual direction is premium industrial: modern, commercially serious, practical, and trustworthy. Hino is the primary brand; `Cebu` is a subordinate location descriptor. Pages remain predominantly white, with charcoal reserved for the homepage hero, footer, and selected emphasis sections. Photography carries visual weight; borders, rounding, shadows, and motion remain restrained.

Do not introduce Tailwind, shadcn, Radix, an animation framework, an icon package, a carousel, or a parallel component system. Refine `Header`, `Footer`, `StickyMobileActions`, `PageHero`, `SectionHeading`, `CtaBand`, `TruckCard`, and the existing card/image classes in place.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, compact internal offsets |
| sm | 8px | Inline controls, compact link groups |
| md | 16px | Default mobile gutter and component spacing |
| lg | 24px | Card padding, tablet gutter, grid gaps |
| xl | 32px | Desktop gutter, component groups |
| 2xl | 48px | Mobile section rhythm, footer group separation |
| 3xl | 64px | Desktop section rhythm and major page separation |

Exceptions: interactive targets must be at least 44px square under WCAG 2.2 AA practice; standard buttons and form controls remain 48px high. One-pixel borders and three-pixel focus outlines are visual strokes, not spacing tokens.

Layout uses an 1180px maximum content width. Container gutters are 16px below 720px, 24px from 720px through 1059px, and 32px at 1060px and above. Grid gaps are 24px. Cards use 24px internal padding. Text blocks should not exceed 64ch for body copy.

## Typography

Use exactly four sizes and two weights across the public website:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 700 | 1.4 |
| Heading | 24px | 700 | 1.2 |
| Display | 48px | 700 | 1.1 |

Display is for page `h1` and major section statements. Heading is for `h2`, `h3`, card titles, and footer group headings; hierarchy below 24px is communicated through semantic level, spacing, and label treatment rather than additional font sizes. Labels include navigation, buttons, eyebrows, form labels, breadcrumbs, status text, and metadata. Uppercase is limited to short eyebrows and footer group labels, with 0.08em letter spacing. Body copy uses normal casing and no negative tracking. Do not synthesize weights or load italics.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Page background, primary content surfaces, header |
| Secondary (30%) | `#F3F4F4` | Cards, alternate sections, mobile menu, quiet panels; charcoal `#17191B` is the inverse secondary reserved for hero/footer/emphasis |
| Accent (10%) | `#D71920` | Primary CTA fill, active-navigation underline, eyebrows/kickers, list markers, and selected conversion emphasis only |
| Destructive | `#A40D14` | Destructive and error text/borders only; always paired with text or an icon |

Accent reserved for: primary conversion buttons; the persistent current-location underline; compact eyebrow/kicker text; feature-list markers; and a single conversion-emphasis surface when needed. Do not use red for ordinary body links, large decorative backgrounds, every hover state, or information that has no conversion/status meaning.

Supporting tokens are charcoal `#17191B`, soft charcoal `#292C2F`, muted text `#62676B`, border `#D9DCDE`, success `#117A46`, warning `#A45E00`, focus `#1378D0`, and darker CTA hover `#A50F15`. Text contrast must meet WCAG 2.2 AA. Focus uses the blue focus token so it remains distinct from red conversion and error states.

Cards use a 1px `#D9DCDE` border, 8px radius, and `0 2px 8px rgb(23 25 27 / 5%)`. Elevated form/finder panels may use a 12px radius and `0 8px 24px rgb(23 25 27 / 8%)`. Buttons use a 4px radius. No glassmorphism, gradients on cards, glow, or layered decorative shadows.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Get a Quote` |
| Empty state heading | `No verified information is available yet` |
| Empty state body | `This section will appear after its details and usage rights are approved. Choose an available Hino Cebu contact option for the next step.` |
| Error state | `We couldn’t show this information. Try again, or use an available Hino Cebu contact option.` |
| Destructive confirmation | Not applicable — this phase introduces no destructive action |

Social-shell unavailable copy is fixed: `Official Hino Cebu social profiles are being verified.` Supporting copy: `Facebook, YouTube, and Instagram links will be added after their destinations are approved.` Use non-clickable text and icons; do not imply a loading failure or invite repeated clicking.

Voice is concise, knowledgeable, useful, and operational. Use specific verb+noun actions: `Explore Trucks`, `Find Your Truck`, `Get a Quote`, `Request Service`, `Ask About Parts`, `Call Hino Cebu`, and `Get Directions`. Do not use hype, fake urgency, unsupported superlatives, or wording that turns national imagery into a Cebu inventory, facility, staff, customer, or availability claim.

## Composition and Responsive Layout

### Header and navigation

- Remove the utility phone strip. The sticky header is 72px high on every breakpoint and sits at `top: 0`.
- Render the approved Hino logo at 124×30px. Place `Cebu` beside or beneath it as a 14px/700 neutral descriptor; it must be visually smaller and quieter than the mark.
- At 1060px and above, render only eligible destinations in this order: `Trucks`, `Find Your Truck`, `Parts`, `Service`, `Hino Cebu`, then `Get a Quote` as the red primary button. A withheld route leaves no gap and is not replaced by inert text.
- The active destination has `aria-current="page"`, a persistent 3px red underline, and a neutral surface hover background. The underline plus semantic current-page state prevents color-only communication.
- Below 1060px, replace desktop links with a 44×44px menu button. The menu is a full-width white panel directly below the 72px header, with 48px minimum rows and the quote action last.
- Menu open/close must update `aria-expanded`; Escape closes it and returns focus to the trigger. Selecting a destination closes it. Do not trap focus, but keep tab order within the visible document flow.

### Hero and page rhythm

- Homepage hero uses a charcoal split surface: copy occupies 42% and approved official truck imagery 58% on desktop. Stack copy then image below 720px.
- Homepage hero image is 16:10 on desktop and 4:3 on mobile, uses `object-fit: cover`, and keeps the full truck cab/body readable at both crops. The current approved Hino 300 image is the fallback until an eligible Cebu-specific hero exists.
- Major interior page heroes use a two-column copy/media layout only when an eligible subject-specific image exists. Otherwise use a clean text-led charcoal or white hero; never fill a local branch/staff/customer slot with misleading national imagery.
- Alternate white and light-neutral sections. Use charcoal for at most the hero, footer, and one emphasis section per page. Red must not become a full page-section background except the final compact CTA band.

### Grids and cards

- Four-column grids collapse to two columns below 1060px and one below 720px. Three-column grids collapse to two between 720px and 1059px and one below 720px.
- Cards align media, title, summary, and action consistently. Use 3:2 media above card content, a thin border, 8px radius, and restrained default shadow.
- Hover may raise a linked card by 2px and strengthen its border; keyboard focus must expose the same affordance without motion. Non-interactive cards do not lift or show pointer cursors.
- Supporting informational sections remain text-led. Do not add decorative images merely to fill whitespace.

### Footer and mobile actions

- Footer is charcoal and conversion-focused. Use four columns at 1060px and above: Hino/Cebu plus branch details; customer paths; support/contact; quote/social/legal. Collapse to two columns from 720px through 1059px and one below 720px.
- Render the approved Hino logo, with Cebu subordinate. Show only eligible branch address, phone, hours, directions, navigation, and legal routes. Place `Get a Quote` as the sole red footer CTA.
- Social presence stays in the footer. Before verification, show muted Facebook, YouTube, and Instagram icons with the fixed unavailable copy and no anchor, button semantics, tab stop, hover treatment, or pointer cursor.
- After a URL is approved, its icon becomes a 44×44px link, opens in a new tab, has `rel="noopener noreferrer"`, and an accessible name such as `Hino Cebu on Facebook (opens in a new tab)`.
- At 720px and below, show a 66px sticky action bar with up to three eligible actions in this order: `Call Hino Cebu`, `Get a Quote`, `Get Directions`. Use these exact visible labels and accessible names; allow each label to wrap to two centered lines within its equal-width action rather than abbreviating it. `Get a Quote` uses the red accent. The grid adapts to the number of eligible actions; no blank slots or reconstructed destinations are allowed. Body bottom padding equals the bar height plus the device safe-area inset.

| Social shell | `unverified`: muted non-interactive row and fixed copy; `verified`: external links with safe attributes and accessible labels; `withheld`: omit destination while retaining the honest shell. |
| Image slot | `eligible`: optimized `next/image`; `no eligible local asset`: omit media or use a clearly product-only official fallback; `withheld`: never expose file reference, reason, or approval diagnostics publicly. |

## Interaction and Motion

- All color, underline, card-hover, and menu transitions use 200ms duration and `ease-out`. Allowed animated properties are `color`, `background-color`, `border-color`, `opacity`, `transform`, and underline scale/position.
- Maximum translation is 2px for cards/buttons and 8px for the mobile menu. No page transitions, parallax, auto-rotating content, autoplay media, scroll-trigger library, or looping decorative animation.
- Under `prefers-reduced-motion: reduce`, transitions and animations are removed and smooth scrolling is disabled. State changes remain immediate and understandable.
- Hover is supplementary. Every control has a visible focus state, and current, expanded, disabled, error, success, and unavailable states include semantic text/attributes rather than color alone.
- Buttons and links keep native semantics. Do not use a clickable `div`. External links identify the new-tab behavior in the accessible name.

| Branch/location | Use an approved Cebu branch photograph only. Until one is eligible, render a structured text/contact panel with no simulated or national-facility image. |

Every image needs fixed dimensions or an aspect-ratio container, responsive `sizes`, an intentional crop, and useful context-specific alt text. Use empty alt text only for a redundant decorative image. Lazy-load below-the-fold media; only the homepage hero is priority. Approved Cebu imagery replaces national fallback imagery subject-by-subject, while official product imagery may remain where it is the clearest model representation.

## Accessibility and Performance

- Maintain semantic landmarks, one page `h1`, logical heading order, skip navigation, visible 3px focus outlines, keyboard-operable navigation, and 44px minimum touch targets.
- Mobile menu labels and state are announced. Social placeholders are plain content, not disabled controls. Icon SVGs are `aria-hidden="true"` when adjacent text supplies the name.
- Navigation, cards, copy, icons, focus, and status combinations must meet WCAG 2.2 AA contrast; verify normal text at 4.5:1 and large text/UI graphics at 3:1.
- Continue server-first rendering. Only the existing header/menu behavior remains client-side; visual polish must not introduce new client state where CSS and Server Components suffice.
- Use `next/image`, explicit `sizes`, stable aspect-ratio containers, and locally served font files from `next/font`. Load two font weights only. Do not add third-party scripts or social embeds.
- Visual changes must not bypass eligible-content selectors, expose pending claims, reconstruct contact destinations, or change lead submission behavior.
